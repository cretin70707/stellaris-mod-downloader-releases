# Stellaris Mod Downloader — releases

Windows builds of **Stellaris Mod Downloader**, a small app that downloads Stellaris Steam Workshop mods with SteamCMD (anonymous login) and registers them with the Stellaris launcher.

- Get the latest version from **[Releases](../../releases/latest)**: download `StellarisModDownloader.exe` and double-click it.
- Already have the app? Use **Settings → About → Check for app updates** — it reads this repo, downloads the new exe, checks it against `SHA256SUMS.txt` and restarts.
- Windows SmartScreen may warn because the exe isn't code-signed: **More info → Run anyway**.

This repo only holds the release files; it is updated automatically.
